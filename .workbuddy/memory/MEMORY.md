## resume-website 技术要点

- 实际渲染数据在 `index.html` 的 `DEFAULT_RESUME_DATA.projects`；但页面显示的是 localStorage 里 `resume-copies` 的活跃副本，改数据不一定立刻生效。
- `migrateGeneratedProjectExamples()` 提供自动迁移：把「旧项目标题对」加入 `generatedTitlePairs`，用户已有的副本会被自动替换为新版 projects。改 projects 内容后可利用这个钩子。
- 数据结构：`title` / `date` / `subtitle` / `tech` / `points[]` / `contentBlocks[]`。
  - `tech` 走 `escapeHtml`，**不能写 HTML**。
  - `subtitle` 在编辑器里是普通 input，保存时会被 strip 掉标签（`replace(/<[^>]*>/g,'')`）——**建议写纯文本**，否则一编辑就丢加粗。
  - `points[]` 走富文本编辑器，**支持 `<strong>` 标签**，可安全使用。
