## 第二轮深挖（三路并行）→ `resume-website/project-highlights.md`

产出物：`resume-website/project-highlights.md`，含两个项目共 28 条硬核点（每条带文件依据 + "难在哪"）、真实可数数字、以及不可写清单。

**mythical-age 最值钱的几条：**
- 动作准入"单权威链"：`AdmissionDecision`(7值) × `ActionPermit` 双门与运算，诊断里明写 `single_authority_chain: admission->action_permit`
- 拒绝指纹去重 + 防原样重试熔断（`repeated_admission_denial`）
- 单轮三条熔断线（连续工具失败 3 / 协议恢复 3 / 工具迭代上限），触发后要求模型**自撰收口**而非硬杀
- 契约编译三段式：`ContractSpec`(acceptance_rules 7 种 / failure_policy / human_gate_policy) → `GraphCompilationUnit` → `deployment_package`
- 任务图 28 种节点 × 6 执行 × 6 等待 × 6 汇聚，编译期穷举校验 20+ 错误码
- Provider 可见追加账本（1730 行）+ 物理前缀帧（1520 行），只有 provider 成功后条目才置 `confirmed_provider_visible`
- 缓存车道不变量（`CACHE_SPINE_LANES` / `TAIL_LANES` / `stable_after_tail_violations`）
- `single_agent_turn.py` 487KB（约 10618 行）；`harness/runtime/compiler.py` 5001 行

**风起千帆最值钱的几条：**
- `AutomationRecoveryService#assess` 交叉四个独立持久化头 → 12 种唯一安全动作
- `DesignRevisionImpact` 用**集合基数断言**（`pendingActions.size() + resolutionRefs.size() == Action.values().length`）把收敛完备性写成构造期约束
- `ReceiptEnvelope` 跨字段一致性（SUCCEEDED 必须非空 outputRefs 且 errorCategory=NONE）
- `PromptContractRenderer` FORBIDDEN 列表（数据库/SQL/ORM/LangGraph/checkpoint/租约…）命中即抛
- `AutomationCheckpoint` 哈希密封（`stateHash=SHA256(...)` 读回重算不符即抛）+ 乐观 CAS
- LangGraph4j 只做单节点自环路由，**完全没用它的 CheckpointSaver**，checkpoint 自管

## ⚠️ 重大发现：风起千帆的接线状态（简历高风险，务必记住）

新内核（`src/main`，550 个 Java 文件）**默认配置下几乎不运行**：
- `@RestController` 命中 **0** —— 无任何 HTTP 层
- 前端 `/api` 代理到 `127.0.0.1:8567`，接的是 **legacy-backend**（59 个 controller），不是新内核
- legacy 与新内核互相引用 **0**，两套完全脱钩
- `application.yml` 里 20 个 `writing.persistence.*` **全默认 memory**；23 处 `matchIfMissing=true`；Jdbc*（53 个）需显式开启
- 无 `spring.datasource`、无 Flyway 连接配置 → **72 张表默认不用**
- **`features.ai.enabled` 默认 false** → `LangChain4jInferenceGateway` 不注册 → 下游 `AgentToolLoop`/`ContextBuilder`/`ModelAgentHandler` 全不注册 → **默认配置下模型根本不会被调用**
- ES 检索同样默认关闭

**简历口径纪律：** 只能说"设计并实现了 XX 内核 / 定义了 XX 协议与不变量"，**不能说**"平台已上线/已支撑 N 部作品/支持读写一体化/已跑通端到端"，也不要写"支持暂停、失败停止和中断后续跑"这类运行期承诺（机制在，运行链路未接）。
