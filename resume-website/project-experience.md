mythical-age——通用型 harness 智能平台

Python · FastAPI · LangChain · SQLite · Next.js · React · TypeScript · MCP · A2A · LlamaIndex

- 项目介绍：面向复杂任务执行的通用 Agent 平台，围绕模型如何在受控边界内持续完成复杂任务，以自研 Harness 框架为运行时宿主。框架之下设能力系统、任务系统、图系统、权限系统、上下文与记忆系统与监控系统，另配前端工作台。
- **Harness 框架：** 自研的运行时宿主框架，一次 Agent 执行的边界集中在此：会话、任务、Agent Profile、Prompt、上下文、记忆与工具统一绑定，聊天与运行监控分别经 WebSocket 与 SSE 输出。开始、暂停、取消、继续与提交由它统一协调。
- **能力系统：** Agent 的装配与能力的注册同在此处。Agent 由运行时 Profile 描述：职责、模型偏好、工具范围、记忆作用域与输出契约在此声明，与任务绑定后生成可执行的运行时规格；模型与记忆等实现载体可替换，任务语义保持稳定。工具、Skill 与 MCP 注册为能力单元，按 Agent 与权限投影为可见目录。
- **任务系统：** 定义要完成什么与完成标准，并把任务声明与执行分离：契约、任务图与拆分规划各自独立描述，由编译器合成可执行图。契约与图结构的合法性在编译期校验完毕，运行期由图系统推进、按契约逐环验收。
- **图系统：** 承担节点与边的推进。Agent 任务的依赖落在成果交付上：上游交付成果之后，下游才具备启动条件；节点就绪据此按入边状态叠加等待与汇聚策略判定。每一步以工作订单派发给能力系统装配的执行体，检查点复用 LangGraph 的存储。
- **权限系统：** 决定一次动作是否允许执行。契约声明允许的操作与资源范围，角色授予基础能力，任务类型、资源路径与风险等级再作细化；可逆读取采用低摩擦策略，高风险写操作要求显式授权。裁决以回执留存依据与范围，供审计、解释与恢复使用，能力目录即其裁决依据。
- **上下文与记忆系统：** 为每一轮调用装配可见输入，并把执行结果沉淀下来。上下文按 Token 压力分三级压缩，优先压缩权威级别较低的冗余输出，保留近期关键消息与高权威事实，并生成结构化恢复包。记忆分五层，检索结果作为带来源的证据进入上下文，候选记忆不覆盖当前用户指令。
- **监控系统：** 承载运行事件日志与健康治理。事件按 run 分配单调偏移与稳定标识，支持按偏移补发、去重与终态对账；健康治理以诊断投影识别卡死、漂移与残留，修复经既有控制接口执行。可观测性覆盖业务、执行、数据与传输四层。
- **工作台：** 基于 Next.js 14 与 React 18 的前端，以事件偏移做状态投影，状态完全由后端事件推导。展示任务运行、图拓扑、工具轨迹与 Token 诊断；刷新或断线后按偏移与后端权威状态收敛。

风起千帆——AI 智能写作平台

Java 21 · Spring Boot 3 · Vue 3 · MySQL · Redis · LangGraph4j · Spring AI

- 项目介绍：面向长篇小说的 Agent 创作平台，以 Agent 操作系统、人机协同数据框架、创作自动化三层为骨干，提示契约、质量门禁与知识检索贯穿其间。各层以统一契约互供任务、上下文与成果回执。链路自创作理念出发，逐级落地为世界观、人物、剧情与大纲，再由多角色 Agent 生成与审核正文，通过的部分沉淀为正文事实、反向更新设定。
- **Agent 操作系统：** 调度创作角色，由会话、意图、任务、运行、租约与回执构成运行对象链。动作经授权后方可执行；作者以一等操作发起接受、驳回、返修与接管。
- **人机协同数据框架：** 面向 Agent 读取、比较、提案与提交的数据操作系统。作品、卷、阶段、章节构成物理层级，人物、事件、组织、规则构成语义对象，二者保存挂接关系。对象以不可变版本承载，AI 的提取结果先作为观察项存在，经采纳才成为事实。一致性分六层，结构、操作、证据与时间由程序保证，语义与协作由 Agent 与作者共同处理。
- **创作自动化：** 驱动创作流水线运行。推进职责分归两处：框架负责循环、条件路由与中断，调度器负责租约、预算与执行权。两者共用一个完成状态。每环产出经审核后方可交接，人工确认的草稿保持锁定；中断之后，由多份独立记录对账得出唯一的恢复动作。
- **提示契约：** 写给创作角色的工作契约，由身份、任务与输出 JSON Schema 三段构成，每个角色各持一份。契约只承载业务语义，实现细节在渲染阶段即被拦截。
- **质量门禁：** 产出交付前的验收关，从事实一致性与跨章连续性评估，据此给出通过、返修或驳回的结论。
- **知识检索：** 为生成与变更供给依据，采用语义与关键词混合召回。
